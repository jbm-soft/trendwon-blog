# Trendwon Blog

Static blog built with **Hugo** and **Tailwind CSS** (Blonde theme).

---

## 🛠 Tech Stack

- **Static Site Generator:** Hugo
- **Styling:** Tailwind CSS & PostCSS
- **Theme:** Blonde

---

## 🚀 Local Development

```bash
# Install Node dependencies
npm install

# Start Hugo dev server
hugo server -D
```
